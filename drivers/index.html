The hero driver

boat.dev passed the kit, 5 of 5.

On a real account, on 2026-11-19. Each check is one thing the kit watched boat.dev do on its real host.

  1. versionpassedIt names the kernel's records version, and prints its schema unchanged.
  2. startpassedIt answered a run id, and the agent's status note appeared on a throwaway ticket.
  3. wakepassedIt reached the same run again: that note was edited, never a second one.
  4. stoppassedIt ended the run: a wake after it was refused, and nothing the run started still runs.
  5. tokenpassedNo credential showed in its output, command lines or environment, and it refused a token field.

Write your own driver

A driver is one small program, in any language, that answers four words. Pass the kit's five checks on your real host and it can join. OpenWiz never touches a login.
