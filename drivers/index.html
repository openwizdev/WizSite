A driver is how a place that runs agents plugs into OpenWiz. Each one answers the same four words, and the test kit checks them on the real host.

  • 4 drivers

boat.devkit 5/5

The hero driver

boat.dev passed the kit, 5 of 5.

On a real account, on 2026-11-19. The kit ran its five checks against boat.dev's driver on its real host.

  1. versionnames the records version it supports, and prints its schema unchanged (passed)
  2. startanswers a run id; the agent's status note appears on the ticket (passed)
  3. wakereaches the same run: that note is edited, never a second one (passed)
  4. stopends the run: nothing it started still runs (passed)
  5. tokenno credential in its output, command lines or environment (passed)

Write your own driver

A driver is one small program, in any language, that answers four words. Pass the kit's five checks on your real host and it can join.

OpenWiz never touches a login.

  • Read the contract kernel/driver.v1.md
  • Run the kit kernel/driver-kit/
  • Copy the template adapters/template/
version
Says the driver's name and its records version.
start
Runs one agent on one ticket, and answers a run id.
wake
Reaches the same run again.
stop
Ends everything the run started.
