Write your own driver

A driver is one small program, in any language, that answers four commands. Pass the same five-check test on your real host and it can join. OpenWiz never touches a login.

Platforms: the test, the template, and the boat.dev and own-computer drivers run on Linux and macOS with the Python version the driver contract names; on a fresh Mac, Python may first ask to install Apple’s Command Line Tools.

Paste this into your agent

›_Write an OpenWiz driver for my host with the write-driver skill: https://github.com/openwizdev/WizSkills/tree/main/skills/write-driver

Your agent writes a driver for your host from the template and runs the same test on your real host. It asks before any step that could cost money or start a machine, never handles a login, and tells you how long it took.
