Write your own driver

A driver is one small program, in any language, that answers four words. Pass the kit’s five checks on your real host and it can join.

version
Says the driver’s name and its records version.
start
Runs one agent on one ticket, and answers a run id.
wake
Reaches the same run again.
stop
Ends everything the run started.

OpenWiz never touches a login.
