Drivers

A driver plugs a place that runs agents into OpenWiz. It answers four words, and the kit's five checks prove it on a real host. OpenWiz never touches a login.

Legend

version
Says the driver's name and records version.
start
Runs one agent on one ticket and answers a run id.
wake
Reaches the same run again.
stop
Ends everything the run started.
