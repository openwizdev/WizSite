# Drivers painted art prompts

## Export and integration

- Desktop canvases: 1664 × 936 (16:9); phone: 675 × 900 (3:4).
- `drivers-b-harbour-phone.webp` is cropped from the accepted harbour generation: source rectangle (650, 0, 1355, 941), then resized to 675 × 900. No separate generation prompt.
- Every export uses Pillow WebP quality 78, method 6, with no EXIF, XMP or ICC profile and no animation. Sea and ship retain the generated alpha channel.
- Voyage layers share one canvas. Stack sky, sea, then ship, without independently cropping their canvases. Sea horizon is around 64% height; ship keel is around 82%. Keep generous overscan for motion; reduced-motion can use the same static stack.
- Direction totals: A 127,036 bytes; B 246,416 bytes; C 75,034 bytes; D 341,824 bytes. Each is below 350,000 bytes.
- These are source artwork deliverables. The page builder must register the selected direction's files in its build allowlist and `ART_HASHES`; this art-only branch intentionally contains no site-code changes.
