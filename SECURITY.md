# Security Policy

## Reporting a vulnerability

Report security vulnerabilities privately through [GitHub private vulnerability reporting](https://github.com/openwizdev/WizSite/security/advisories/new).

Please do not open a public issue for a security vulnerability.

## Scope

This policy covers the public pages on `openwiz.dev` (including `/app/`) and the `/api/*` Cloudflare Pages Functions in this repository.

For vulnerabilities in OpenWiz itself, report them on [openwizdev/OpenWiz](https://github.com/openwizdev/OpenWiz/security/advisories/new).

## Response

We aim to acknowledge new reports within 3 business days and keep you updated as we investigate and fix the issue.
