What is OpenWiz?

OpenWiz is a free, open source kernel for agent factories. It runs fleets of AI coding agents such as Claude Code and Codex on your own computers or cloud machines, with work tracked in GitHub.

What it does

You decide what gets built and approve the plan. Your agents write the spec and tickets, then build, review and merge the work.

How it works

Specs, tickets and agent status live in your repository’s GitHub issues. Code and reviews go in pull requests.

A driver connects OpenWiz to the machine that runs your agents. Each driver answers four commands: version, start, wake and stop. The driver test kit checks a driver on its real host.

Where your agents run

OpenWiz ships drivers for your own computer or VPS, CloudRoom and boat.dev. See the driver list for test results.

What it costs

OpenWiz is free and released under the Apache License 2.0. Supporter is $5 per month for priority support and to support the project. It adds nothing else to the software. See Pricing. You pay for the models and machines you use.

How to install

Not to be confused with

OpenWiz at openwiz.dev is the agent factory kernel from the GitHub organization openwizdev. Other projects and domains with the same name are unrelated.
