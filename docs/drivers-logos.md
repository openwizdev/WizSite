# Drivers page logos

Every logo on the [Drivers page](https://openwiz.dev/drivers/) is its owner's official mark, fetched from the owner's own site, press kit or official repository. The one exception is `monitor.svg`, a generic icon. Each file is unaltered apart from size; none is recoloured, cropped, framed or redrawn. Where a brand ships a light variant for dark backgrounds, that variant is used. "Check" records the comparison made on 2026-11-23: the committed file against a fresh download of its source. The page says: "Logos belong to their owners. They name the products these drivers and harnesses are for, not a partnership, and not what runs today: each tile says its state." `scripts/check.py` pins each file's bytes.

## Names shown without a logo

A mark is used only when its owner's terms, as far as they can be read, allow this use and the page meets every condition they set. Otherwise the tile shows the name in text:

- **Fly Sprites:** Fly.io's [Trademark Usage Agreement](https://fly.io/docs/about/brand/#trademark-usage-agreement) asks for written authorization and a link from the mark to Fly.io's homepage. There is no authorization on record.
- **GitHub Codespaces and GitHub Copilot CLI:** [GitHub's logo rules](https://github.com/logos) ask for prior written permission and limit the standalone Invertocat. [The Copilot brand guide](https://brand.github.com/brand-identity/copilot) deprecates the standalone Copilot icon. There is no permission on record.
- **JetBrains Junie:** the [JetBrains brand guidelines](https://www.jetbrains.com/company/brand/) are rendered by a script, so their terms could not be read in full here. JetBrains is reported to require copyright and trademark attribution with a link to its homepage. So the page doesn't use the mark.
- **Mistral Vibe:** Mistral's logo kit download was refused (403). The only Vibe icon found, in Mistral's official repository, is black only, and Mistral's brand page forbids recolouring and framing the mark.
- **OpenComputer:** its site serves only a dark wordmark, with no light variant for this dark page.
- **Grok Bot:** xAI's brand guidelines could not be read (the request was refused), and the page has never shown a Grok logo.
