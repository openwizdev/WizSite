# Drivers page logos

Every logo on the [Drivers page](https://openwiz.dev/drivers/) is its owner's official mark, fetched on 2026-11-23 from the owner's own site, press kit or official repository. Each file is unaltered apart from size; none is recoloured, cropped, framed or redrawn. Where a brand ships a light variant for dark backgrounds, that variant is used. The page says: "Logos belong to their owners and show what OpenWiz can run on, not a partnership." `scripts/check.py` pins each file's bytes.

## Names shown without a logo

- **Mistral Vibe:** Mistral's logo kit download refused the request (403), and the only Vibe icon found, in Mistral's official repository, is black only. Mistral's brand page forbids recolouring and placing the mark in a frame, so it can't sit on this dark page.
- **OpenComputer:** its site serves only a dark wordmark, with no light variant, so it would not show on this dark page.
- **Grok Bot:** xAI's brand guidelines could not be read (the page refused the request), and xAI's terms require permission, so the page has shown no Grok logo since it began.

The shipped drivers' marks (`boat-dev.svg`, `cloudroom.png`, `monitor.svg`) predate this table.
